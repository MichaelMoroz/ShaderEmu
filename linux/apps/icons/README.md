# Icons the Chicago95 set has none for

`tools/make_icons.py` brings each down to 32 and 16 pixels for the desktop's sheets
(`linux/apps/icons.txt` names them). They are their projects' own:

| File | Whose | From |
|---|---|---|
| `doom.png` | Chocolate Doom (GPL-2.0) | `data/doom.png` of https://github.com/chocolate-doom/chocolate-doom at `chocolate-doom-3.1.0` |
| `quake.png` | id Software's Quake source release (GPL-2.0) | `WinQuake/quake.ico`, its 32-pixel picture, at the commit `linux/quake/build.sh` names |
| `classicube.png` | ClassiCube (BSD-3-Clause) | `misc/CCicon.png` at the commit `linux/classicube/build.sh` names |
| `tdawn.png`, `ralert.png` | Vanilla Conquer (GPL-3.0) | `resources/vanillatd_icon.svg` and `vanillara_icon.svg` at the commit `linux/tdawn/build.sh` names, drawn at 256 pixels |
| `nxchess.png` | this project's | a knight of DejaVu Sans on two squares, by `python tools/make_chess_pieces.py` |
| `glxgears.png`, `nxeyes.png`, `halflife.png` | this project's | drawn by `python tools/draw_icons.py`: the demo's three gears in its colours, two eyes, an orange lambda in a ring |
| `micropolis.png` | Micropolis (GPL-3.0 with EA's terms) | `content/micropolis/tilesets/classic/icon1.ico` (the X11 release's 32-pixel map) at the commit `linux/micropolis/build.sh` names |
| `openttd.png` | OpenTTD (GPL-2.0) | `media/openttd.128.png` at the tag `linux/openttd/build.sh` names |
| `quake3.png` | ioquake3 (GPL-2.0) | `misc/quake3.png` at the commit `linux/quake3/build.sh` names |
| `aoe.png` | this project's | a temple on its steps with the sun behind, drawn for it (nothing of the game's) |
| `jk2.png` | this project's | a blue light sword up the diagonal, drawn by `python tools/draw_icons.py` (nothing of Jedi Outcast's) |
