A file as a PNG picture

The ShaderEmu world in VRChat can only be handed pictures. This page wraps any file into a PNG whose pixels are the file's bytes; put that PNG on a host that serves it unchanged (no resizing, no conversion to JPEG) and paste its https address into the world's "Open a link" field. Nothing leaves this page: the work is done in your browser.

Drop a file here, or

Up to 12 MB (a picture of 2048 x 2048). The format is in docs/fetch.md; tools/file_to_png.py does the same.
